# 🛡️ 異常觀測修復計畫：校園守護者

## 📖 專案簡介
這是一個專為 **國小四年級學生** 設計的互動式邏輯閱讀遊戲。玩家將化身為「校園觀測員」，在多變的校園場景中，透過閱讀感測報告，過濾掉受污染的異常訊號，守護校園空間的邏輯穩定。

## 📜 觀測員生存手則 (遊戲規則)
在校園感測報告中，穩定訊號絕對不會出現以下狀態。若在觀測卡片中察覺下列違和行為，請立即將其移入 **「異常隔離區」**：

*   **🚶 物理邏輯錯誤**：例如「倒著走路」、「腳尖朝後卻向你逼近」、「反方向倒退滑行」。
*   **👤 違反常規社交**：例如「臉部平滑沒有五官」、「沒有呼吸起伏卻在說話」。
*   **🔇 感官描述矛盾**：例如「沒開燈的暗處傳來打字聲」、「沒插電的螢幕顯示文字」、「物品自行產生共振」。
*   **🌀 空間結構異常**：例如「牆上突然出現通往地下的樓梯」、「原本三樓的樓梯轉彎後變成九樓」。

## 🎮 遊戲核心特色

### 🎭 敘事化情境融合
遊戲捨棄了死板的指令條列，將「異常標籤」深度埋入具備敘事感的長句子中。學生必須從整段環境描述中，透過閱讀理解找出隱藏的「違和感」，而非單純搜尋關鍵字。

### 🎲 動態多樣性題庫
*   **地標隨機化**：系統每次從 15 個校園地標中隨機抽取 7 個，並由玩家選取 3 個進行觀測。
*   **描述去固定化**：每個地點均配備多組正常與異常描述，確保每次遊戲體驗的句子皆不重複，徹底打破記憶標準答案的作法。

### 🛡️ 雙重隔離邏輯
系統不僅考驗學生是否抓出「異常」，同時也檢測是否誤判了「正常」訊號。採用拖放式操作（Drag & Drop），強化手眼協調與分類思維。

### 🔍 精準檢討機制（後設認知）
任務結束後提供「報告分析詳細清單」，針對玩家的選擇進行動態回饋。
*   **✅ 成功攔截**：給予正面肯定，標註已排除的威脅。
*   **❌ 未攔截異常**：以紅色醒目標示遺漏的關鍵細節，協助學生即時反思。

## 👨‍🏫 教學應用建議

1.  **高層次閱讀策略**：訓練學生在複雜敘述中，辨識出「主詞（誰）」與「異常狀態（做了什麼）」的對應關係。
2.  **科學邏輯推理**：討論為什麼「沒插電的電腦有聲音」或「倒著走路的人」在現實物理規律中是不合理的。
3.  **創意寫作引導**：鼓勵學生觀察校園角落（如：地下室入口、老樹下），嘗試練習「校園怪談式」的敘事創作。
